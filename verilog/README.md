# Verilog Notes

This directory contains my Verilog notes, examples, and learning roadmap.

## Learning Roadmap

### Phase 1: Verilog Fundamentals 

* Verilog syntax and basic concepts
* Modules and ports
* Operators
* Data types
* Testbenches
* Basic logic gates

### Phase 2: Sequential Logic 

* D Flip-Flops
* Synchronous and asynchronous reset
* Enable Flip-Flops
* T, JK, and SR Flip-Flops
* Registers
* Counters
* Shift Registers

### Phase 3: Finite State Machines 

* Moore FSM
* Mealy FSM
* FSM design methodology
* State diagrams
* State encoding

### Phase 4: Combinational Building Blocks 

* Multiplexers (2:1, 4:1, 8:1, parameterized)
* Decoders
* Encoders
* Priority Encoders
* Comparators
* Arithmetic circuits (Adders and Subtractors)

### Phase 5: ALU Fundamentals

* ALU architecture
* Arithmetic unit (ADD, SUB)
* Logic unit (AND, OR, XOR, NOT)
* Shift unit (Logical and Arithmetic)

### Phase 6: ALU Project

* Parameterized ALU (8-bit or 16-bit)
* Arithmetic operations
* Logical operations
* Shift operations
* Compare operation
* Status flags (Zero, Negative, Carry, Overflow)
* Self-checking testbench
* Yosys synthesis and verification
* Documentation

## Projects I'll Build

* Parameterized Multiplexer Library
* Decoder Library
* Encoder Library
* Comparator
* Parameterized ALU
* Comprehensive ALU Testbench
* fifo
* uart
* 4 bit cpu

These notes are based on what I learn while studying Verilog and will continue to grow as I improve my RTL design skills.
